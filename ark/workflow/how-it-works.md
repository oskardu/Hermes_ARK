# 每一步怎么做

> 工作流各环节的详细说明。

## Step 6: UI & Animation Design

### 6.1 视觉研究

**做什么**：搜集同行业/同风格的视觉参考，产出视觉 Moodboard。

**怎么做**：
- 输入：产品定位、行业、风格偏好
- 搜集参考图，整理为 moodboard

**产出物**：Moodboard 图片集

### 6.2 视觉工作坊（可选）

**做什么**：基于 moodboard 探索多个视觉方向。

**说明**：此步骤可选——当 AI 能直接从 moodboard 提取视觉语言时，工作坊可以跳过。

**怎么做**：
- 输入：moodboard + 交互稿
- 产出 3-4 个不同视觉方向的可预览方案
- 团队选择方向

**产出物**：多个视觉方向的 HTML/CSS 预览

### 6.3 提取视觉语言【关键步骤】

**做什么**：从选中的视觉方向中提取结构化视觉语言，产出 DESIGN.md。

**为什么是关键步骤**：它是整个工作流的枢纽。没有结构化的视觉语言文档，AI 无法在后续环节中保持一致性。这一步的质量直接决定后续所有产出的质量。

**怎么做**：
- 输入：选中的 moodboard / 视觉方向
- 提取色彩、字体、间距、圆角、阴影、渐变、布局、动效等
- 产出扩展版 DESIGN.md 文档

**产出物**：DESIGN.md（视觉语言文档）

### 6.4 关键页面 + 动效设计

**做什么**：基于视觉语言 + 交互稿，产出核心页面视觉设计和动效。

**怎么做**：
- 输入：DESIGN.md + 交互稿
- 产出 HTML/CSS 原型
- 浏览器预览确认效果
- 确认后通过支持直连 Figma 的 Agent + Figma MCP 同步到 Figma

**产出物**：HTML/CSS 原型 → Figma 文件

### 6.5 其余页面延展

**做什么**：基于确定的视觉语言，AI 批量延展剩余页面。

**核心价值**：这是 AI 改变成本结构的关键环节——边际成本趋近于零。

**产出物**：全套页面视觉设计

## Step 7: Design System

**做什么**：从设计语言和页面设计中总结 Design System，实现设计资产的结构化沉淀。

**产出物**：
- Design Token 文件（结构化数据）
- Figma 中的 Design System
- 说明文档
