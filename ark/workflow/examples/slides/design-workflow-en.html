the core pain

Style
Transfer
Fails

Current DESIGN.md format lacks the granularity to describe visual language, resulting in insufficient style fidelity. It cannot reliably reproduce visual style across different products and interaction designs.

Specific gaps: visual density (whitespace ratio) / shadow system (multi-layer, glassmorphism) / gradient patterns / motion specs (easing, duration) / reference imagery / image treatment (rounded corners, overlays, filters)

Solution
Extend DESIGN.md format to cover these dimensions
