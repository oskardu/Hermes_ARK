# 工作流概述

> 用 AI Agent 执行 UI 设计的完整流程，共 9 步。

## 核心命题

**AI 改变视觉设计的成本结构**——让多方向探索的边际成本趋近于零。

## 四个核心目标

| 层次 | 目标 | 关键词 |
|------|------|--------|
| 生产层 | 快速产出视觉方向 | 速度 |
| 生产层 | 高效延展页面设计 | 规模 |
| 连接层 | 产出可交互 Demo | 验证 |
| 连接层 | 打通生产环境（Design System + Figma） | 落地 |

## 核心痛点

传统视觉流程横跨 8 个环节，每多探索一个视觉方向，资源消耗线性增长。团队被迫收敛方向数，牺牲探索质量。

AI 的本质价值：不是优化某个环节，而是改变整个成本结构。

## 流程图

```
1. 需求对接
   ↓
2. 研究（竞品、用户、技术）
   ↓
3. 产品设计（PRD、功能规划）
   ↓
4. UX Design（交互架构、流程、文案）
   ↓
5. 低保真交互 Demo（可选）
   ↓
6. UI & 动效设计 ← AI 重点参与
   ├─ 6.1 视觉研究 → 产出 Moodboard
   ├─ 6.2 视觉工作坊（可选，AI 可替代）
   ├─ 6.3 提取视觉语言 → DESIGN.md【关键步骤】
   ├─ 6.4 关键页面 + 动效设计
   └─ 6.5 其余页面延展（AI 批量产出）
   ↓
7. Design System 沉淀 ← AI 重点参与
   ↓
8. 高保真 UI Demo（可选）
   ↓
9. 交付开发（Figma 文件等）
```

## AI 参与优先级

| 优先级 | 环节 | 说明 |
|--------|------|------|
| 🔴 最高 | 快速产出视觉方向 | 多方向并行，边际成本趋近于零 |
| 🔴 最高 | 高效延展页面设计 | 从 N 周缩短到 N 小时 |
| 🟡 次高 | 产出可交互 Demo | 原型先行，降低返工成本 |
| 🟡 次高 | 打通生产环境 | Design System + Figma 直连 |

## 技术路径（推荐）

1. **视觉语言文档**：基于 Google DESIGN.md 格式扩展
2. **视觉设计产出**：Hermes 生成 HTML/CSS → 确认 → 同步到 Figma
3. **Figma 连接**：通过支持直连 Figma 的 Agent + Figma MCP 实现
